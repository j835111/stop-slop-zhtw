# Stop AI Slop · 繁體中文版

讓 AI 寫出來的中文不再像 AI 寫的。

這是一套提示詞 Skill，給 Claude / GPT / Gemini / 文心 / 通義 / DeepSeek 等模型用，識別並消除中文 AI 寫作的典型痕跡：套話、排比三件套、名詞化動詞、抽象主語、金句收尾、總分總八股。

靈感來自 [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop) 英文專案，但**不是翻譯**——中文 AI 味跟英文 AI 味的指紋完全不一樣，整套規則、詞表、句式、評分都是為中文重做的。

---

## 這套規則解決什麼

你大概見過這樣的中文：

> 在當今 AI 蓬勃發展的時代，我們正面臨前所未有的機遇與挑戰。AI 不僅是一種工具，更是一種思維方式，是推動社會進步的重要力量。讓我們以更開放的姿態擁抱變化，共創美好未來。

每一句都對，但你一眼能看出是 AI 寫的。本 Skill 要解決的就是這種"每一句都對、但合在一起就是 AI"的問題。

## 專案結構

```
.
├── SKILL.md              核心：8 條改寫規則 + 5 維評分 + 工作流
├── README.md             本文件
└── references/
    ├── phrases.md        12 類禁用詞彙黑名單（約 200 條）
    ├── structures.md     15 類句式套路（含三件套 / 名詞化 / 抽象主語等）
    └── examples.md       4 個場景 7 組 Before/After 改寫範例
```

## 怎麼用

### 方式 1：Claude Code（推薦）

把整個目錄放到 Claude Code 能掃到的 skills 路徑下，或直接 `cd` 到本目錄後，第一句對話告訴 Claude：

> 請按 SKILL.md 的規則改寫下面這段中文。改完後給五維打分。

Claude 會自動讀取 SKILL.md 和 references。

### 方式 2：Claude Projects / ChatGPT Projects

把 `SKILL.md` 和 `references/*.md` 全部上傳到 Project 的知識庫。然後在系統提示或第一句對話裡寫：

> 你扮演中文 AI 味消除助手。所有改寫任務都要遵循 SKILL.md 中的 8 條規則與 5 維評分。模糊時優先查 references/phrases.md 和 references/structures.md。

### 方式 3：單次 API 呼叫 / Cherry Studio / 其他客戶端

把 `SKILL.md` 全文塞進系統提示。`references/*.md` 可以按需放入，或拼成一個長 prompt。

最小可用 prompt 模板：

```
你的任務是消除中文 AI 寫作痕跡。嚴格按以下規則操作：

[此處貼上 SKILL.md 全文]

每次改寫後，按五維評分（直/實/變/散/真，每維 1-10）打分，
低於 35/50 重寫直到達標。

使用者輸入：[待改寫文本]
```

### 方式 4：作為人工校稿清單

不接 LLM 也能用。`SKILL.md` 第四節"交付前清單"是 9 條人工查的項目，寫完文章對著清單走一遍。

## 用法建議

- **不要邊寫邊查**。先把想說的寫完，再用本 Skill 改寫。邊寫邊查會丟失思路。
- **從 phrases.md 第 1 / 5 / 7 / 10 類開始**：這四類（開場套話 / 程度副詞 / 雞湯收尾 / 價值判斷飽和）命中率最高，最快見效。
- **重災區是三件套排比**。改寫時優先全文搜「，是」「，更是」「既要」「不僅」，命中的位置看一下要不要拆。
- **35/50 是底線，不是目標**。要讓文本讀起來像人寫的，至少 42+。
- **作者的具體經歷是最強武器**。AI 寫不出來的不是技巧，是你知道而 AI 不知道的細節。

## 邊界與坦誠

這套規則不是萬能的：

- **公文 / 黨政文稿**：裡面的"總分總"和價值判斷是規範，不是 AI 味。本 Skill 在這類文本上要保守使用。
- **法律 / 合約**：精確性優先，名詞化和長定語是必要的。
- **學術論文**：被動語態和抽象主語在學術寫作裡是常態，不必強拆。
- **小紅書 / 抖音文案**：本身就是高度套路化的格式，本 Skill 的目標變成"換一種套路"而不是去套路化。

詳見 SKILL.md 第五節"什麼時候不該用本 Skill"。

## 持續更新

中文 AI 文本的指紋在變。模型更新一輪，套話就換一批。

新詞收錄標準：在三篇不同來源（不同模型 / 不同 prompt / 不同作者）的 AI 輸出裡都出現過，才進黑名單。避免誤傷個人風格。

歡迎回饋遇到的新型 AI 套話，特別是：
- 某個模型 / 某個版本的特有指紋
- 某個垂直領域（醫美、母嬰、金融）的套話
- 你試過本 Skill 但發現沒蓋到的場景
