# 改寫示例：Before / After

四個典型場景。每例都標註改了什麼、為什麼。原文是真實 AI 生成（或貼近 AI 輸出的稿）的樣子，改寫示範"去 AI 味"的具體動作。

---

## 場景一：公眾號 / 知乎長文

### 例 1.1 · 科技評論

**Before（AI 味濃）：**

> 在當今人工智慧蓬勃發展的時代，AI 正在以前所未有的速度重塑我們的工作方式。從內容創作到程式碼撰寫，從資料分析到決策輔助，AI 的觸角已經延伸到我們生活的方方面面。
>
> 不可否認，這是一場深刻的變革。它不僅僅是工具的升級，更是思維方式的革命，是人類文明發展的又一個里程碑。
>
> 然而，值得注意的是，技術的進步從來都不是一帆風順的。我們必須認識到，機遇與挑戰並存，藍海與暗礁同在。唯有保持敬畏之心，方能在 AI 浪潮中行穩致遠。

**問題診斷：**
- 第一段：抽象主語「AI」做事，三件套排比「從…到…，從…到…」
- 第二段：「不僅僅是…更是…是…」三件套 + 抽象昇華
- 第三段：「不可否認 / 我們必須認識到 / 唯有…方能…」全是空殼，金句結尾
- 全篇沒有一個具體的人、一個具體的數字、一個具體的場景

**After：**

> 我們組三個工程師，過去半年有兩個把日常除錯丟給了 Claude。剩下那個還在用斷點法，每次 review 都比另外兩個慢半天。
>
> 去年說"AI 寫程式碼"聽起來還像段子，現在再說就是一句陳述句。變得太快——三月份我剛學的 prompt 技巧，到十月份模型自己就懂了，技巧白學。
>
> 但寫程式碼不是全部。我家樓下影印店老闆用 AI 寫公眾號，三個月漲了 2000 粉，比他自己寫一年都快。他不懂"AI 時代"是什麼，他只看後台資料。

**改了什麼：**
- 刪了所有「在 XX 時代 / 浪潮 / 里程碑 / 行穩致遠」類抒情
- 抽象主語「AI」換成具體人物（同事、影印店老闆）
- 拆掉所有三件套
- 給了三組具體數字（3 個 / 2 個 / 半年 / 2000 粉 / 3 個月）
- 段落長度刻意不同（短-中-中）
- 沒有金句收尾

### 例 1.2 · 職場雞湯類

**Before：**

> 在這個快節奏的時代，焦慮似乎成了每個人的標配。我們焦慮工作，焦慮收入，焦慮未來。其實，焦慮的本質，是對失控的恐懼。
>
> 那麼，我們該如何應對焦慮呢？首先，要學會與不確定共處；其次，要建立自己的核心能力；最後，要保持對生活的熱愛。
>
> 願你在喧囂的世界裡，找到屬於自己的節奏。願你不被焦慮裹挾，做時間的朋友，做自己的主人。

**問題診斷：**
- 「在 XX 時代」開場
- 「焦慮 A，焦慮 B，焦慮 C」三件套
- 「焦慮的本質，是 XX」AI 最愛的「XX 的本質是 XX」句式
- 反問句「我們該如何 XX 呢？」自問自答
- 「首先 / 其次 / 最後」八股
- 「願你 / 願你 / 做 XX 的朋友 / 做 XX 的主人」金句收尾 + 三件套

**After：**

> 我上次焦慮發作是上個月，凌晨三點，原因是想到房貸還有 18 年。
>
> 翻身起來做了三件事：把工資條找出來核了一遍存款；查了如果裸辭夠撐幾個月（答案：7 個月）；列了一份"明天要做的事"，三條。做完這三件事，我睡著了。
>
> 這套不能治本，但能讓我從"完蛋了"變成"那現在幹什麼"。夠用。

**改了什麼：**
- 刪開場背景，直接進具體場景（凌晨三點 / 18 年）
- 拆「焦慮 A B C」排比
- 「我們該如何 XX」反問 → 直接說"做了三件事"
- 刪「首先 / 其次 / 最後」八股，用動詞序列代替
- 刪「願你 / 願你」金句結尾
- 末段是結論，不是昇華

## 場景二：小紅書 / 短文案

### 例 2.1 · 產品推薦

**Before：**

> 姐妹們！今天必須給大家安利一款寶藏護膚品！🌟
>
> 這款精華真的太太太愛了！它不僅能深層補水，還能淡化細紋，更能提亮膚色，是一款集多重功效於一體的全能型選手！
>
> 用了一個月，皮膚狀態明顯改善，整個人都煥然一新！這就是好產品的力量！寶子們衝就完事了！

**問題診斷：**
- 「姐妹們 / 安利 / 寶藏 / 寶子們」高度套路化（這就是小紅書 AI 文案的指紋）
- 「不僅 A，還 B，更 C」三件套
- 「全能型選手」AI 套詞
- 「明顯改善 / 煥然一新」空泛形容
- 「這就是 XX 的力量」金句收尾
- 「衝就完事了」AI 模仿網感詞的常見誤用

**After**（保留小紅書風但去掉 AI 指紋）：

> 用了 28 天，記錄在手機備忘錄裡。
>
> 用之前：T 區出油到中午要補妝，左臉頰有一片粗糙摸起來像砂紙。
> 用之後：T 區還是出油但補妝從中午延到下午 4 點，砂紙感的位置肉眼看不出來了，摸還有一點。
>
> 一瓶 380，30ml，省著用夠兩個月。不踩雷。

**改了什麼：**
- 刪「姐妹們 / 寶子們 / 安利 / 寶藏」全部套路稱呼和熱詞
- 刪 emoji（AI 加 emoji 的位置很規律）
- 拆「不僅 A 還 B 更 C」
- 把「明顯改善」換成具體觀察（T 區 / 中午 / 4 點 / 砂紙感）
- 給具體數字（28 天 / 380 / 30ml）
- 刪金句結尾

**注意**：小紅書本身是高度套路化的平台，完全去套路就不像小紅書了。這裡的目標是"保留小紅書的具體感和實測感，去掉 AI 模仿小紅書的尷尬感"。

### 例 2.2 · 探店

**Before：**

> 探店日記 | 一家藏在巷子裡的寶藏咖啡館 ☕
>
> 推開門的瞬間，彷彿進入了另一個世界。原木色調的裝修溫馨而治癒，氤氳的咖啡香撲面而來，讓人瞬間忘卻城市的喧囂。
>
> 這裡的每一杯咖啡都是匠心之作，是咖啡師對咖啡的熱愛，是一種生活態度的表達，更是一份與城市對話的溫柔。
>
> 在這個浮躁的時代，能有這樣一個角落，真的太治癒了。強烈推薦！

**問題診斷：**
- 「藏在巷子裡的寶藏」AI 探店專用套句
- 「彷彿進入另一個世界 / 忘卻喧囂」陳詞比喻
- 「氤氳」AI 偏愛的"文藝"詞
- 「是 A，是 B，更是 C」三件套
- 「在這個 XX 的時代」+ 「真的太 XX 了」+ 「強烈推薦」三連套話

**After：**

> 探店 | 長壽路 487 弄拐進去第二家
>
> 老闆自己烘豆，店裡只有六個位子。我去的下午兩點沒人，三點開始陸續來人，到四點要拼桌。
>
> 點了哥倫比亞水洗手沖，48 塊。豆子剛開封三天，喝得出花香沒有酸。配了一塊巴斯克，蛋香蓋過焦味，不甜。
>
> 缺點：洗手間要去隔壁麵館借。

**改了什麼：**
- 刪「藏在巷子裡」「寶藏」開篇套話，換成具體地址
- 刪比喻「另一個世界 / 忘卻喧囂」，換成觀察（六個位子 / 兩點沒人 / 三點來人）
- 拆「是 A，是 B，更是 C」
- 刪「氤氳 / 治癒 / 浮躁的時代」抒情
- 給具體的咖啡名、價格、品鑑細節
- 加一條缺點——AI 幾乎從不主動寫缺點，寫了缺點立刻像真人

## 場景三：公文 / 工作匯報（邊界場景）

公文有結構要求，"總分總 / 首先其次"不全是 AI 味，是格式要求。這裡示範的是**在保留公文規範的前提下**去掉 AI 痕跡（多餘的抒情和價值判斷飽和）。

### 例 3.1 · 專案週報

**Before：**

> 一、本週工作概述
>
> 本週，在領導的關心和支持下，在各部門的密切配合下，專案組全體成員凝心聚力、攻堅克難，圓滿完成了既定目標。我們以高度的責任感和使命感，扎實推進各項工作，取得了顯著成效。
>
> 二、主要進展
>
> 首先，我們對系統架構進行了優化；其次，我們對使用者回饋做出了回應；再者，我們對相關 bug 加以解決。
>
> 三、下週計劃
>
> 下週，我們將再接再厲，砥礪前行，以更加飽滿的熱情投入工作，為專案的順利推進貢獻力量。

**問題診斷：**
- "在領導的關心和支持下" 這類政治套話——如果是黨政公文這是規範，如果是企業內部週報就是 AI 自動加的
- 「凝心聚力 / 攻堅克難 / 責任感和使命感」成語堆砌
- 「顯著成效」無具體
- 「進行了優化 / 做出了回應 / 加以解決」名詞化三連
- 「再接再厲 / 砥礪前行 / 飽滿的熱情 / 貢獻力量」金句結尾全套

**After**（企業內部週報版本）：

> **本週進展**
>
> 1. 把訂單查詢介面的回應時間從 1.2s 降到 280ms。瓶頸在 N+1 查詢，加了批量預先載入。
> 2. 處理了上週使用者回饋的 12 條問題，其中 9 條已修復，2 條轉產品評估，1 條無法復現。
> 3. 修了三個線上 bug：登入狀態丟失、列表分頁錯位、價格四捨五入偏差。
>
> **下週**
>
> 重寫支付回調的冪等邏輯。預計三天。如果遇到第三方文件不清楚的地方可能延到週五。
>
> **風險**
>
> 測試環境資料庫下週二要遷移，可能影響聯調。已和測試組對齊。

**改了什麼：**
- 刪開場客套
- 把「進行了優化 / 做出了回應 / 加以解決」全部去名詞化，換成具體動作 + 數字
- 刪「再接再厲 / 砥礪前行」收尾，換成具體下週計劃
- 主動加「風險」段——真實的工作匯報會有風險/阻塞，AI 生成的只會畫餅

## 場景四：學術 / 研究類（邊界場景）

學術寫作允許被動語態、抽象主語、長句——但 AI 寫的學術文本仍有可識別的"偽學術"指紋：過度概念化、空泛價值判斷、引用堆砌但不深入。

### 例 4.1 · 論文摘要

**Before：**

> 隨著人工智慧技術的飛速發展，大語言模型在自然語言處理領域展現出了巨大的潛力。本文旨在探討大語言模型在文本生成任務中的應用現狀與未來發展趨勢。
>
> 通過對相關文獻的梳理與分析，本文發現，當前大語言模型在文本生成方面取得了顯著進展，但仍面臨諸多挑戰。這些挑戰既有技術層面的，也有倫理層面的，更有社會層面的。
>
> 本文認為，未來的研究應當注重多維度的協同發展，以期推動該領域的持續繁榮。

**問題診斷：**
- 「隨著 XX 的飛速發展 / 巨大的潛力」開場套話
- 「旨在探討 XX 的現狀與未來發展趨勢」AI 摘要標準句
- 「顯著進展 / 諸多挑戰」無具體
- 「既有 A，也有 B，更有 C」三件套
- 「應當注重多維度的協同發展，以期推動該領域的持續繁榮」純空話收尾

**After：**

> 本文對 2023–2025 年間 47 篇 LLM 文本生成相關論文做了系統綜述，重點檢查三個指標：評估方法、人類偏好對齊、長文本一致性。
>
> 主要發現：(1) 80% 的論文用 BLEU/ROUGE 作為主要指標，但這兩個指標與人類評分相關係數僅為 0.31。(2) RLHF 類方法在短文本上效果穩定，但在超過 2000 token 的生成任務中崩塌率高於純監督微調。(3) 評估資料集嚴重偏向英文，中文長文本評估缺乏統一基準。
>
> 據此提出三點建議：放棄 BLEU 作為主指標；構建中文 4k+ token 評估集；分離短文本與長文本基準。

**改了什麼：**
- 刪「隨著 XX 的發展」開場
- 「本文旨在」→ 直接說做了什麼（綜述 47 篇 / 2023–2025 年）
- 「顯著進展 / 諸多挑戰」→ 三條具體發現，帶數字
- 刪「既有 A 也有 B 更有 C」
- 「應當注重多維度的協同發展」→ 三條具體建議
- 摘要長度差不多，但資訊密度從 0 變成可引用

## 通用改寫流程（看完示例後的總結）

每次改寫按這個順序過，命中率最高：

1. **刪開場背景**（"在 XX 時代 / 隨著 XX 發展"）
2. **找抽象主語**，換成具體的人 / 團隊 / 數字
3. **拆三件套排比**（搜「，是…，是…，更是…」/「既要…也要…還要…」）
4. **去名詞化**（搜「進行 / 實現 / 做出 / 採取 / 加以 / 給予」）
5. **刪價值判斷飽和詞**，每一個都問"能換成具體嗎"
6. **刪段尾金句**（"這就是 XX 的力量"等）
7. **刪元評論**（"接下來 / 讓我們 / 在本文中"）
8. **檢查段落長度方差**，過於均勻就主動打亂

按這個流程過一遍，普通 AI 輸出能從 25/50 提到 38/50 左右。剩下的提升靠加具體內容——AI 不知道的、只有寫作者本人才知道的細節。

## 最重要的一句

**消除 AI 味的本質不是"換詞"，是"給具體"。**

任何抽象、任何套話、任何昇華——背後都是 AI 因為不知道細節而不得不抽象。你知道細節，所以你能寫得不像 AI。把你知道的細節寫進去，AI 味自然就沒了。
