# 中文 AI 套話詞彙黑名單

按"違規嚴重程度 + 出現頻次"排序。看到表裡的詞，先問一句：刪掉它意思變了嗎？沒變就刪。

---

## 1. 開場套話（破題句）

中文 AI 最愛用宏大背景開頭，彷彿在寫學測作文。

| 套話 | 問題 |
|---|---|
| 在當今 XX 的時代 / 背景下 | 任何內容都套得上，等於沒說 |
| 隨著 XX 的不斷發展 | 套話開頭，下一句必是空話 |
| 在這個資訊爆炸的時代 | 比喻磨損嚴重 |
| 在科技日新月異的今天 | 標準 AI 起手 |
| 眾所周知 / 不可否認 / 顯而易見 | 真的眾所周知就不用寫 |
| 自古以來 / 自人類文明誕生之初 | 強行拉歷史縱深 |
| 在 XX 蓬勃發展的浪潮中 | "浪潮" 二字基本都是 AI |
| 21 世紀是 XX 的世紀 | 八股開頭 |
| 當我們談論 XX 的時候 | 沒必要的預告 |

**改寫思路**：第一句直接是觀點、事實、場景或衝突，不要背景鋪墊。

---

## 2. 八股連接詞（過渡套話）

整段全是連接詞撐骨架，刪了之後文章一樣成立。

| 套話 | 用法 | 改寫方向 |
|---|---|---|
| 首先 / 其次 / 再者 / 最後 | 分點骨架 | 直接講，不用"首先" |
| 綜上所述 / 總而言之 / 總的來說 | 結尾收束 | 刪掉，讓最後一句自然成為結尾 |
| 概括而言 / 歸根結底 | 總結 | 同上，刪 |
| 由此可見 / 不難看出 / 顯而易見 | 推論 | 刪，或換成具體推理 |
| 與此同時 / 與之相對 | 並列 | 直接換行另起一段 |
| 一方面 …… 另一方面 …… | 二分 | 拆成兩段或換句式 |
| 不僅如此 / 更重要的是 | 遞進 | 刪，讓遞進靠內容自身 |
| 然而 / 因此 / 此外 / 同時 | 高頻連接 | 減半，能省就省 |
| 接下來 / 接下來讓我們 | 預告 | 刪，直接進入內容 |
| 在此基礎上 / 基於此 | 學術腔過渡 | 改成具體動作描述 |

## 3. 強調虛殼（看似有力其實空的開頭）

這些短語後面 99% 跟一句沒營養的話。

- 值得注意的是
- 值得一提的是
- 值得關注的是
- 不得不說
- 不可否認
- 毫無疑問
- 不容忽視
- 我們必須認識到
- 需要明白的是
- 需要指出的是
- 必須承認
- 讓我們正視
- 客觀來講 / 客觀地說
- 坦白說 / 老實說 / 說實話
- 在我看來（寫第一人稱文章時可保留，但密度別太高）

**判斷方法**：把這句開頭去掉，句子本身還成立嗎？成立就刪。

## 4. 網路 / 商業黑話

2018 年之後中文網路產出的造詞，AI 訓練資料裡濃度極高。在公眾號、產品稿、徵才文案裡要尤其警惕。

### 4.1 動詞類
賦能、抓手、打通、對齊、串聯、閉環、跑通、沉澱、復盤、拉齊、拉通、收斂、發散、聚焦、輻射、引爆、撬動、激活、釋放、加持、加碼

### 4.2 名詞類
顆粒度、心智、底層邏輯、鏈路、漏斗、增長飛輪、第一性原理、信息差、認知差、勢能、勢位、生態位、護城河、勢在必行、勢能差、心智佔領、用戶畫像、價值傳遞、深度鏈接、生態構建、護城河

### 4.3 形容/狀態
高維、降維、垂直、橫向、縱深、立體、生態、生態化、規模化、平台化、垂類、長尾、頭部、腰部、尾部、抗週期、反脆弱

### 4.4 流行黑話
捲、內捲、躺平、破圈、出圈、入局、破局、出海、上岸、躬身入局、風口、賽道、解決方案、痛點、爽點、癢點、剛需、強需求、弱需求

> **判斷標準**：能不能用普通人聽得懂的詞替代？能就替代。  
> 例：「賦能銷售團隊」→「讓銷售賣得更順」「給銷售配工具」  
> 例：「打通使用者心智」→「讓使用者記住我們做什麼」

## 5. 程度副詞 / 虛詞泛濫

中文 AI 的"刷量詞"，刪了幾乎不損失任何資訊。

### 5.1 程度副詞
非常、十分、極其、相當、特別、格外、尤其、極度、超級、巨、賊、好、很（每千字不超過 5 個"很"）

### 5.2 模糊語氣
真的、確實、的確、實在、其實、本質上、說白了、本來、本身、原本

### 5.3 虛化量詞
一種、某種、一定的、相應的、一定程度上、在某種意義上、一類、一系列、一系列的

### 5.4 名詞化動詞搭子（刪搭子保留動作）

| 搭子 | 改成 |
|---|---|
| 進行 + N | 直接動 |
| 實現 + N | 直接做 |
| 做出 + N | 做 |
| 採取 + N | 具體動作 |
| 加以 + N | 直接動詞 |
| 給予 + N | 給 |
| 提供 + N | 給 / 提供（少用） |
| 起到 + 作用 | 起作用 / 直接說做了什麼 |
| 發揮 + 作用 | 同上 |
| 形成 + 局面 / 態勢 | 寫出具體形成了什麼 |

> 例："對演算法進行優化" → "優化演算法"  
> 例："對問題加以解決" → "解決問題" / "把問題解決了"  
> 例："起到了一定的推動作用" → "推動了 XX" / 資料化

## 6. 元評論（自我指涉）

AI 喜歡預告自己要做什麼、解釋自己為什麼這麼寫。這些都該刪——讀者要的是內容，不是導覽。

- 讓我們來探討 / 讓我們來分析 / 讓我們一起 / 讓我們看看
- 接下來我將 / 接下來我們將 / 下面我們來看
- 在本文中 / 本文將 / 這篇文章會
- 以下是幾點 / 以下幾個方面 / 下面分幾點講
- 讓我為你詳細講解 / 讓我來告訴你
- 我會從 XX 入手 / 我會先講 XX 再講 XX
- 在開始之前 / 在進入正題之前
- 說到這裡 / 講到這裡
- 回到正題 / 言歸正傳（除非確實離題了）
- 我想說的是 / 我想表達的是

**原則**：直接說事，不要解釋"我接下來要說什麼"。

## 7. 雞湯收尾 / 抒情擴散

AI 段尾癖好。看到這些詞在段末，刪整句。

### 7.1 直接金句
- 願你 / 願我們 / 願每一個 XX
- 未來可期 / 道阻且長 / 行而不輟
- 讓我們一起 / 共創美好 / 攜手前行 / 同行
- 你值得擁有 / 你不是一個人
- 與 XX 同行 / 向陽而生 / 奔赴山海
- 不負韶華 / 不負 XX
- 心之所向 / 素履以往
- 山高水長 / 來日方長

### 7.2 句式化升華
- "這，就是 XX 的力量"
- "這，就是 XX 的意義"
- "唯有 XX，方能 XX"
- "因為 XX，所以 XX 才顯得彌足珍貴"
- "在這個 XX 的時代，我們更需要 XX"
- "或許，XX 才是真正的 XX"
- "XX，永遠在路上"
- "致敬每一位 XX"

### 7.3 假深沉
- 人生如逆旅 / 歲月如歌 / 時光如水
- 三千繁華 / 一念之間
- 路雖遠，行則將至

**判斷標準**：這句話能套到任何主題上嗎？能就刪。

## 8. 排比強化型套話（句尾結構）

不是所有排比都壞，但 AI 用的排比有固定模板。

- "是 XX，是 XX，更是 XX"
- "是一種態度，是一種選擇，是一種生活方式"
- "不僅是 XX，還是 XX，更是 XX"
- "既是 XX，也是 XX，又是 XX"
- "為了 XX，為了 XX，也為了 XX"
- "我們要 XX，我們要 XX，我們更要 XX"

**改寫策略**：保留三句裡最有力的一句，其餘刪；或者改成不同句式說出。

## 9. 假親切稱呼

AI 模仿"親民"內容時高頻使用。除非確認是面向私域社群的特定場景，否則一律刪。

- 親愛的讀者 / 親愛的朋友
- 朋友們 / 各位朋友
- 家人們（極強 AI / 直播話術指紋）
- 寶子們 / 寶寶們
- 各位看官 / 列位
- 小夥伴們（程式設計/技術部落格慎用，已被 AI 濫用）
- 各位老鐵
- 你我皆是 XX / 我們都是 XX

## 10. 價值判斷飽和詞

形容詞不要花錢不要錢地撒。這些詞每出現一次都要問"能不能換成具體的"。

- 重要、關鍵、核心、必不可少、不可或缺、舉足輕重
- 顯著、明顯、巨大、深遠、深刻、深邃
- 優秀、卓越、出色、突出、傑出
- 強大、有力、紮實、穩健、穩固
- 全新、嶄新、煥然一新、耳目一新
- 璀璨、奪目、閃耀、絢爛
- 極致、終極、完美、無可挑剔

> 例："帶來了顯著的提升" → "載入從 4.2 秒降到 0.8 秒"  
> 例："是核心能力" → "如果沒這個，整個流程跑不通"

## 11. 四字成語濫用

成語本身無罪，但 AI 文本裡成語密度異常高，且偏愛一組特定的"正能量成語"。同段不超過 1 個，全篇不堆砌。

**高頻 AI 成語**（看到要警覺）：
博大精深、源遠流長、生機勃勃、欣欣向榮、蓬勃發展、日新月異、與時俱進、推陳出新、獨樹一幟、獨具匠心、精益求精、匠心獨運、錦上添花、畫龍點睛、點石成金、點亮未來、照亮前行、引領潮流、勇立潮頭、披荊斬棘、攻堅克難、風雨同舟、砥礪前行、篤行不怠

**判斷**：如果連續兩句話各用一個四字成語，刪一個。如果一句話裡兩個成語並列，刪一個。

## 12. 比喻庫存（被 AI 用爛的比喻）

這些比喻本身可能曾經鮮活，但被訓練資料裡反覆使用，已經是套話。

- 像一把雙刃劍
- 好比一座橋梁 / 是連接 XX 的橋梁
- 如同 XX 的燈塔 / 指明方向
- 是 XX 的引擎 / 發動機
- 是 XX 的基石 / 基礎 / 根基
- 是 XX 的催化劑
- 像一面鏡子，映照出
- 如同一棵大樹 / 一顆種子
- 是一場馬拉松 / 不是百米衝刺而是馬拉松
- 是 XX 的密碼 / 鑰匙
- 是 XX 的天花板 / 上限

**改寫方向**：如果一定要比喻，找一個跟內容緊密相關、讀者不太可能見過的比喻；找不到就直接說，不比喻。

## 使用說明

這份清單不是要"逐詞消滅"，是要建立**敏感度**。

- 寫作時：不必邊寫邊查
- 改寫時：從清單 1 → 5 → 7 → 10 順序掃一遍（命中率最高的幾類）
- 校稿時：用搜尋功能批量找 "首先 / 進行 / 一種 / 讓我們 / 非常 / 綜上"，每個都問一遍要不要

清單會持續更新。新增 AI 套話以"在三篇不同來源的 AI 輸出裡都出現過"為收錄標準。
